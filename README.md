# КОМУ НА ВИХІД? — демонстраційний інтернет-магазин

Навчальний проєкт. Відкрийте `index.html` у браузері або опублікуйте папку через GitHub Pages.

## Публікація
1. Створіть новий публічний репозиторій `komu-na-vykhid`.
2. Завантажте **вміст** цієї папки до кореня репозиторію (index.html, images, .nojekyll).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Посилання матиме вигляд https://ВАШ-ЛОГІН.github.io/komu-na-vykhid/ . Перевірте його в Settings → Pages.

Це демосайт: жодних реальних платежів, замовлень або передачі даних. Ціни та ілюстрації концептуальні.
